大家好，我今天要把上次沒講完的縮網址給講完喔 如果你是第一次看到這篇文章，不知道啥麼是縮網址的話，可以[按我前往](https://sln98106.pixnet.net/blog/post/54618724)了解什麼是縮網址。   那我們就進入正題吧，今天只講中文的喔，所以會講得很細喔<--還真詳細啊(酸   [ppt.cc](http://ppt.cc/) [![bandicam 2014-01-23 16-48-41-102](https://farm6.staticflickr.com/5476/12098854295_1d763a973c_b.jpg)](https://www.flickr.com/photos/107928128@N03/12098854295)  成立四年的縮網址服務 為了讓這項服務能持續下去，所以會有一些限制，網址必須大於19個字元(包括前面的https://) 稍微講一下，「我同意使用規範」選項旁的「防堵機器人」選項，就是你在縮出網址之後給使用者點之後，會有驗證碼來請你輸入，之後才能導向你指定的網址 [![bandicam 2014-01-23 16-48-45-626](https://farm4.staticflickr.com/3688/12099133153_f7a288481a_b.jpg)](https://www.flickr.com/photos/107928128@N03/12099133153) 這是密碼保護的設定頁面 [![bandicam 2014-01-23 16-50-35-077](https://farm8.staticflickr.com/7395/12099229414_4dac81ed4e_b.jpg)](https://www.flickr.com/photos/107928128@N03/12099229414) 這個是你產生出來的縮網址頁面，按連結下方的\[QR條碼\]可以看到這個縮網址的QR code [![bandicam 2014-01-23 16-48-50-268](https://farm4.staticflickr.com/3813/12098855585_24c9a3f7b0_b.jpg)](https://www.flickr.com/photos/107928128@N03/12098855585) 這個是檔案保護，就是有點像密碼一樣，但和密碼不同的是，你必須上傳一個檔案(ppt.cc的大小限制是500kb)，使用這個必須持有你當初上傳的檔案，才能去到你指定的連結 原理的話，大概就是檔案的[MD5](https://briian.com/6457/hashmyfiles.html)吧(謎之聲:沒人問你這個，你幹嘛多嘴。小恩:我自己想說嘛) [![bandicam 2014-01-23 16-52-39-081](https://farm4.staticflickr.com/3756/12098855325_2ce24f552f_b.jpg)](https://www.flickr.com/photos/107928128@N03/12098855325) 這個是使用者點入加密的連結出現的授權頁面 如果是用密碼加密的話，點「輸入密碼」再把你設定的密碼打進去就好了 [![bandicam 2014-01-23 16-55-49-783](https://farm6.staticflickr.com/5499/12098855065_d2b71fe3bc_b.jpg)](https://www.flickr.com/photos/107928128@N03/12098855065) 如果是用檔案加密的話，把當初上傳的檔案給它就好了 [![bandicam 2014-01-23 16-55-55-827](https://farm3.staticflickr.com/2810/12099229094_439f13cebb_b.jpg)](https://www.flickr.com/photos/107928128@N03/12099229094) 這個是解密完或是打完驗證碼之後的樣子，按一下連結就可以到目的網址了   以上，ppt.cc的說明到此結束   [4fun.tw](https://4fun.tw/) [![bandicam 2014-01-23 16-56-12-744](https://farm4.staticflickr.com/3826/12099513296_a4ca9a7748_b.jpg)](https://www.flickr.com/photos/107928128@N03/12099513296) 這個了話我不知道要說甚麼了(謎之聲:那麼你可以滾了) 長度限制是19個字元(包含https://) [![bandicam 2014-01-23 16-56-14-873](https://farm4.staticflickr.com/3761/12099513016_c615c979a4_b.jpg)](https://www.flickr.com/photos/107928128@N03/12099513016) 這個是安全設定，個人感覺「保存期限」和「安全門」的功能還蠻好用的 「保存期限」是指這個連結可以活多久，只要過了你設定的日期，這個連結就失效了 「安全密碼」就是使用者進入連結的時候，必須輸入密碼(這還需要說嗎?) 「安全門」就是縮網址只在你能從你設定的網址點擊，從其他來網頁點擊都會失效(謎之聲:怎們跟他們的網頁說明有些相似。小恩:巧合而已(汗)) [![bandicam 2014-01-23 16-56-44-936](https://farm8.staticflickr.com/7389/12099512826_b11a047f4b_b.jpg)](https://www.flickr.com/photos/107928128@N03/12099512826)  這是連結產生後的樣子 [![bandicam 2014-01-23 16-57-02-811](https://farm6.staticflickr.com/5473/12099228494_39048144e1_b.jpg)](https://www.flickr.com/photos/107928128@N03/12099228494)  這是一般沒經過任何設定的縮網址點開後的樣子，按一下左下角的\[立即前往\]就可以到達指定網址囉 [![bandicam 2014-01-23 16-57-57-050](https://farm4.staticflickr.com/3721/12099228464_872861879b_b.jpg)](https://www.flickr.com/photos/107928128@N03/12099228464)  這是有經過加密的縮網址，把密碼打下去之後按\[讓我過!\]就可以到指定的網址了 [![bandicam 2014-01-23 16-59-26-139](https://farm6.staticflickr.com/5535/12098854445_c4d0f221eb_b.jpg)](https://www.flickr.com/photos/107928128@N03/12098854445)  這東西叫做流量統計，怎麼使用呢 舉個例子：假如你縮出來的網址是
